# Manual execution register

Use the case ID and the fixture commit when recording a manual result. Capture the browser, OS, input, actual behavior, status, and evidence link.

| Scope | Actual result | Status | Evidence |
| --- | --- | --- | --- |
| OD-01 through OD-11 | Dedicated manual execution was outside the local verification pass. | Not run manually | [Automated evidence and environment](../../06-Test-Reports/README.md) |

A passing automated check may cover part of a manual case. Keyboard-only interaction, responsive layout and accessibility inspection require their own result when executed.
