# SDLC and STLC

| Delivery activity | QA activity and output |
| --- | --- |
| Discovery | Identify testable requirements, risks and acceptance gaps. |
| Design | Write the test strategy and agree on observability and fixtures. |
| Implementation | Design cases and add deterministic checks at the contract and UI levels. |
| Integration | Verify environment health, run suites, triage failures and collect evidence. |
| Release | Apply exit criteria and record residual risk and approval. |
| Maintenance | Retest incidents, add targeted regression coverage and refine the suite. |
